# DevOps Docker Project

This repository contains a simple DevOps project demonstrating Docker containerization.

## Project Structure

- `app/`: Node.js web application
- `scripts/`: Shell scripts for running Docker commands
- `docker-compose.yml`: Docker Compose configuration
- `docker-commands-log.md`: Log of Docker commands run during class
- `.github/workflows/`: CI/CD pipeline using GitHub Actions

## Getting Started

1. Clone the repository
2. Navigate to the project directory
3. Run the demo script: `./scripts/run-docker-demo.sh`
4. Or manually build and run with Docker Compose: `docker-compose up --build`

## Docker Commands Used

See [docker-commands-log.md](docker-commands-log.md) for a record of all Docker commands executed.
